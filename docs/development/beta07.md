# β07の開始点と実装方針

β06の最終コミット[899a47f](https://github.com/shogo314/rusk_b_06/commit/899a47fdc8811dd64e917550ed5459af99a3146e)を引き継ぎ、β07の開発を開始する。β06の[全テストCI](https://github.com/shogo314/rusk_b_06/actions/runs/42463022653)と[ドキュメント公開](https://github.com/shogo314/rusk_b_06/actions/runs/42463022642)の成功を確認して区切った。このリポジトリのGit履歴は新しく開始している。

## 今回の目標

変更・副作用・共有・脱出の情報を中間表現に明示し、解析結果から安全な最適化を行う。言語機能と標準APIはβ06を引き継ぐ。詳しい要件はリポジトリの[design/beta07.md](https://github.com/shogo314/rusk_b_07/blob/main/design/beta07.md)にまとめる。

1. 引数や値への読み取り・中身の更新・コンテナの構造変更・共有先の保持や返却・コールバック呼び出しの効果を表す。
2. HIRで具体的な関数の効果を求め、LIRにも保持・反映する。externや解析できない処理は保守的に扱う。
3. 値が戻り値・コンテナ・フィールド・enum・捕捉などを通じて外へ保持されるかを解析する。
4. 寿命を保証できる一時参照の借用、非脱出スカラーの値保持、不要なコピーや検査の削減へ利用する。
5. 通常版・最適化無効版の比較、共有と寿命のテスト、サニタイザー、公開問題、ベンチマークで検証する。

## 現在の状態

**新しい解析と最適化は未実装。** 開始時点でコンパイラ・標準ライブラリ・テストはβ06の最終版と同じである。リポジトリの案内・要件・Pagesの公開先をβ07へ切り替えた段階で、最適化の成果を主張するものではない。

## 引き継いだ課題と測定

[β06の生成C++の調査](beta06.md)で、Rusk版find・sumの反復で一時的なshared_ptrのコピーと参照カウント操作が多いことを確認した。findは通常のRusk関数へ移行済みで、速度退行が残る。sumは既存のextern実装を維持している。

β07ではfindの移行時退行を対象にし、sumもRusk実装と既存実装を比較して移行を判断する。特定の関数名だけの専用処理に偏らず、通常のRusk関数へ適用できる解析とする。既存の11項目の測定も維持する。

比較用に、β06のソースを`/tmp/rusk_b_06-899a47f.tar.gz`、リリース版コンパイラを`/tmp/rusk-beta06-baseline`へ保存した。環境が変わった場合はβ06の最終コミットから再ビルドする。[開始点の情報](beta07-baseline.json)にコミット・検証結果・比較用コンパイラのハッシュを記録する。

## 守る規則

`=`と`:=`、共有・コピー・評価順、更新の可視性、文字参照と走査中の変更検査、取得済み要素の寿命、位置付き実行時診断を維持する。実験用C++の借用への置換や検査削除を、そのまま一般のプログラムへ適用することはしない。解析結果から安全を説明できる範囲で実装する。
